# Retired Electron Desktop

The Electron product is retired. Its implementation and historical instructions
remain available in Git history at `612af25`. The supported graphical application
is [Assistant (Tauri)](../docs/assistant/ASSISTANT_DESKTOP.md).

See [product consolidation and history preservation](../docs/architecture/PRODUCT_CONSOLIDATION.md)
before accessing an existing workspace or uninstalling an older application.
Retirement does not delete installed applications, user data, worktrees or keys.
