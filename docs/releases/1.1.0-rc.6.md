# 1.1.0-rc.6 candidate readiness

Prepared on 2026-09-22. RC.6 is unpublished and targets npm `next`.
It supersedes the tagged but unpublished RC.5; existing tags are not moved.

## Certification behavior

- Keep Qwen `qwen3.8-flash`, Meta `muse-spark-1.2`, and OpenAI `gpt-5.6-luna` pinned in the new assembly mapping. Historical mappings remain unchanged.
- Stop subsequent release gates and providers after a confirmed failure. Start representative evaluation only after live certification passes. Preserve exhaustive manual diagnosis and bounded transient retries.
- Checkpoint completed representative cases and retain them across report failures. Record the finalization phase and allowlisted error structure without messages, prompts, provider bodies, credentials or stacks.
