# 1.1.0-rc.2 candidate readiness

Prepared on 2026-09-22. Targets npm `next`; publication and release-bound
certification remain pending. Stable `latest` remains 1.0.0.

## Scope and failure correction

RC.2 carries the compatible console, local service and Desktop preview work from
[RC.1](1.1.0-rc.1.md), plus the correction integrated in
[PR #91](https://github.com/Zhivex/zhivex-harness/pull/91).
Desktop remains a separate private 0.1.0-alpha.1 preview.

The [RC.1 release attempt](https://github.com/Zhivex/zhivex-harness/actions/runs/35675370387)
validated the tarball and general live providers but did not publish:

- Meta and OpenAI each passed 14/14 representative samples, then evidence generation
  failed because RC.1 lacked external model pins.
- Qwen passed 12/14 samples. Local reproduction of the clean hostile-instructions
  case exposed `Agent compaction result still exceeds maxEstimatedInputTokens`.

The shared assembly matrix now pins this exact candidate. Release readiness and
regression tests reject missing current-version pins before protected live work.
The governed driver retains two recent messages instead of six; the SDK preserves
correlated tool groups. The 12,000-token ceiling and all approval, OCI and
independent verification requirements remain intact. Historical 1.0 evidence is
validated separately and has not been rewritten.
