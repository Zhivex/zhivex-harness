The four engine/client-to-CLI occurrences are `client/adapter.ts` importing
`terminal-continuation` and `run-document`, plus `client/json-contracts.ts` and
`client/service-events.ts` importing `cli-stream`. These are shared semantics
to move inside Harness, not a justification for Harness to depend on Code.
Desktop imports the four existing `internal/desktop` bridges, not a published
package API. ACP launcher imports interactive CLI configuration.

This AST inventory covers literal imports/re-exports/require/import types. It
does not prove absence of computed loads or all runtime cycles. The ADR defines
the acyclic target and implementation gates; the current graph is not certified
as the future package layout.
