# Validación RC9 con SDK next.2

Core 1.23.0-next.2 y Agents 1.9.0-next.2 instalados desde registry con Bun y versiones exactas; override Core actualizado para conservar una identidad de runtime. Providers sin nuevas versiones next respecto del candidato anterior.

## Resultado

- `bun run check:sdk-redaction`: 8/8 combinaciones pasan. Generate/stream, memoria/archivo reabierto y permitir/rechazar. Salida final y estado persistido saneados. Los chunks anteriores al guardrail terminal permanecen fuera del gate y de la garantía documentada.
- `bun run check`: aprobado, incluyendo paquete instalado RC9. El primer intento dentro del sandbox falló en ocho tests por EPERM al abrir sockets; el segundo con permisos apropiados pasó completo.
- Smoke base live: Qwen 3.8 Flash, OpenAI gpt-6-luna y Muse Spark 1.3 pasan aprobación, efecto único y reinicio, un caso cada uno.
- Orquestación Qwen: primer caso aprobado con hijo persistido y reapertura; segundo caso rechazado por GuardrailTriggeredError, delegation=acceptance, checkpoint=orchestration_status. No se distingue todavía omisión del padre frente a rechazo del hijo.
- La segunda serie de orquestación se detuvo antes de OpenAI/Meta. No se ejecutaron routing, OCI live ni matriz representativa tras el fallo confirmado. Los casos base de esos proveedores pertenecen a una ejecución independiente iniciada antes de conocer ese fallo.

El defecto de redacción reproducido está corregido; no demuestra que la variabilidad de Qwen esté resuelta. Conservar Flash y el bloqueo de publicación. No hubo tag ni dispatch de release. La evidencia local no reemplaza la certificación completa del artefacto inmutable.
