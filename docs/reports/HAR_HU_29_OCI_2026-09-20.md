# HU29 — OCI previews and patch-bound verification

The environment has a read-only preview operation for existing run/scope artifacts.
It validates metadata/environment binding, patch identity and host digest/mode
preconditions without acquiring a runtime or creating snapshots. Full before/after
contents include create/update/delete and permission changes. Invalid UTF-8 fails
instead of replacing bytes during display or import. Import-time checks remain.

The client and desktop projections support apply_environment_patch,
verify_and_apply_environment_patch and verify_and_apply_reviewed_edits. Complete,
unredacted previews enable the existing one-use decision path. Verified reviewed
edits show host-bound content; the execution transaction retains its clean-snapshot
and unchanged-verifier-patch gates. OCI execution configuration remains host-owned.

Verified history requires matching run/import patch identity, exact approved argv,
exit zero without timeout, and the reviewed-edits proposal identity where relevant.
It exposes patchId/command/exit evidence; unrelated plain checks explicitly do not
certify a specific patch. Invalid or mismatched receipts stay unconfirmed.
