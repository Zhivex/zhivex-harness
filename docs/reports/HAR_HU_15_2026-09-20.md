# HAR-HU-15 — Console input and streaming

Source: [Notion user story](https://app.notion.com/p/3e1777b104f681c2b4f2dbe0f04a75e5).
Implementation branch: `feat/har-hu-15-console-input-streaming`.
Baseline: `c7d0799018cb105f6d583b60b344d9697ae01395`.

## Reproduction and changes

Feeding the baseline ConsoleInput a bracketed clipboard containing `first line`
and `second line` resolved the question as `first line` before a separate Enter.
The regression now requires the clipboard to remain an editable draft. Clipboard
markers and UTF-8 may span input chunks; controls are escaped, drafts are bounded
to 64 KiB, oversized inserts retain the prior draft, and Ctrl+C cancels an
unfinished paste. Slash-prefixed pasted tasks remain literal on submission and
history recall. Approval prompts ignore bracketed clipboard answers.

Input is filtered before readline, so typing while a run is active cannot echo
over provider output or answer a later approval. Resize is forwarded to readline
only during an active question or multiline capture; it cannot erase partial model
output to repaint an inactive prompt. Existing Node cursor editing, Alt+Enter,
Tab completion, in-memory history and durable cancellation are reused.

The existing markdown renderer flushes unfinished lines on a 50 ms timer, with
explicit flushing on success and error paths. Existing activity, approval and
completion labels remain separate. Provider controls remain visibly escaped.
No JSON/JSONL schema, stable API or durable-state migration was introduced.

partial streaming and Ctrl+C, provider disconnection after partial output,

## Boundaries

- Implemented and verified locally; no push, PR, registry publication or live
  provider certification is claimed by this report.
- Primary terminal behavior was verified with Node on macOS. Linux/Node 24 and
  Bun interactive terminal parity were not verified in this session; the support
  matrix is unchanged. Bun remains the development/test/package tool used here.
- Terminals without bracketed-paste support must use the existing `/paste` flow.
- Ctrl+C intentionally discards unsent drafts; submitted tasks remain recoverable
  through process-local history. History is neither persisted nor shared with
  approval input. Markdown styling is best effort across delayed fragments.
- HAR-HU-13 remains Backlog in Notion at implementation time. Its first-use
  acceptance criteria are a separate deliverable; this work reuses the working
  1.0 console and does not mark that dependency complete.
