## Explicit boundaries

Experimental v1 is an in-process contract for one trusted, exclusive writer per workspace/scope. Connection-scoped idempotency keeps up to 1,024 receipts without eviction; it is not a durable exactly-once guarantee. A new connection epoch requires state reconciliation. Expected revisions are preconditions within that ownership boundary, not cross-process coordination. Cancellation is at durable pause points; active-run cancellation is not advertised.

Queries reconcile durable state, but an interrupted start with an index reference and no run fails closed rather than guessing whether an effect occurred. Successful approval payloads and output are sensitive project content; a future service needs authenticated access. Engine-denied tools can yield EXECUTION_FAILED and are never represented as successful execution.

HU-22 adds the service transport, HU-23 durable replay, HU-24 coordinated multi-client approval/cancellation and HU-25 CLI service integration. No server, desktop architecture, release, registry publication or broad support certification is inferred. The earlier pilot's HOLD for 1.1 is unchanged by this contract work.
